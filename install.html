Install

A Mac on macOS 13 or later, and a phone on the same Wi-Fi.

  1. 01

    Download and drag into Applications

    Download PadRemote.dmg All versions

    Open it and drag PadRemote onto Applications. Apple Silicon or Intel. It lives in the menu bar — no window, no Dock icon.

    It isn't notarized yet, so the first open says macOS could not verify it. Click Done, then System Settings → Privacy & Security → Open Anyway. Once is enough. Every step, with updating and uninstalling →

    Or build it yourself

    git clone https://github.com/padremote/padremote cd padremote && ./install.sh

    Needs Rust and Node. Installs to ~/Applications, offers to start it at login, and launches it. Use one install or the other, not both.

  2. 02

    Grant Accessibility

    System Settings → Privacy & Security → Accessibility → enable PadRemote. An app that moves your cursor needs it, and macOS owns that decision.

    The grant is per app and per build, so a new download or a rebuild needs it again: remove PadRemote from the list with – and grant it fresh. install.sh clears the stale one for you.

  3. 03

    Scan the code

    Menu-bar icon → Connect a device…, then point your phone's camera at the QR and tap the link. That is the pairing done.

    Don't post the code anywhere: until that first connection it is the key to your computer.

Or run it from source

cd web && npm install && npm run build
cargo run --manifest-path desktop/Cargo.toml

The page is compiled into the app, so build it first. Useful flags: --dry-run, --headless, --port, --unpair.

What isn't done yet

Not notarized

The download needs one Open Anyway the first time, and Accessibility again after each update.

No TLS

The link is plain ws://: readable on your Wi-Fi, but not usable.

macOS only

Windows and Linux compile and are tested, but have never run on real hardware.
